# Categoría Documental: Reference (Referencias Externas)

## Propósito
Esta carpeta es el repositorio central para toda la documentación técnica y legal externa que influye o condiciona el desarrollo de CajaFácil. Almacena las especificaciones de terceros sobre las cuales el equipo de CajaFácil no tiene control directo de edición.

## Alcance
*   **Qué pertenece aquí:** Hojas de especificaciones de hardware (ej. manuales de ticketeras térmicas de clientes), legislación fiscal vigente (ej. leyes de facturación del país), manuales de integración de pasarelas de pago y documentación oficial de librerías externas.
*   **Qué NO pertenece aquí:** Reglas internas del negocio o manuales de arquitectura del proyecto.

## Propietario
*   **Rol:** Lead Architect / Product Owner.

*   Reglas impositivas y de negocio en `docs/business/`.
