# Categoría Documental: History (Historial y Cierres de Sprint)

## Propósito
Esta carpeta es el repositorio de archivo para el conocimiento histórico del proyecto. Almacena actas de sprints pasados, auditorías técnicas puntuales que ya fueron resueltas y especificaciones funcionales descartadas u obsoletas.

## Alcance
*   **Qué pertenece aquí:** Reportes de finalización de sprint, reportes históricos de auditoría técnica y especificaciones marcadas con `status: obsolete`.
*   **Qué NO pertenece aquí:** Documentación viva del sistema actual o estándares vigentes.

## Propietario
*   **Rol:** CTO / Lead Architect.
