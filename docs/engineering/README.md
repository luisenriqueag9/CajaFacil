# Categoría Documental: Engineering (Ingeniería de Software)

## Propósito
Esta carpeta es el paraguas técnico consolidado para todo el conocimiento de diseño de software, bases de datos, decisiones de arquitectura y estándares de codificación de CajaFácil.

## Alcance
*   **Qué pertenece aquí:** Subcarpetas de arquitectura macro (`architecture/`), persistencia relacional (`database/`), guías y estándares de codificación (`standards/`) y registro de decisiones de diseño (`adr/`).
*   **Qué NO pertenece aquí:** Reglas comerciales puras, leyes fiscales o manuales de proveedores externos (deben ir en `business/` o `reference/`).

## Propietario
*   **Rol:** Lead Architect.

## Estructura Interna
*   `architecture/`: Diseño macro, bounded contexts y flujo general de datos.
*   `database/`: Esquemas de datos conceptuales, lógicos y físicos relacionales.
*   `standards/`: Directrices técnicas de código, linters, testing y onboarding.
*   `adr/`: Registro histórico y cronológico de decisiones arquitectónicas (ADRs).
