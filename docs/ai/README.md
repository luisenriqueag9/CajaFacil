# Categoría Documental: AI Adaptor (Adaptador de Contexto para Inteligencia Artificial)

## Propósito
Esta carpeta sirve como adaptador de contexto oficial optimizado para asistentes de IA y agentes de desarrollo autónomos. Su estructura y contenidos están condensados y libres de ruido para minimizar el consumo de tokens y maximizar la precisión en la generación de código.

## Alcance
*   **Qué pertenece aquí:** Guías abreviadas del patrón maestro máster, estándares condensados de codificación y PR checklists de verificación rápida.
*   **Qué NO pertenece aquí:** Monolitos de documentación obsoletos, guías extensas o actas de sprints pasados.

## Propietario
*   **Rol:** AI Architect / DevOps.

## Documentos Canónicos
*   `00_LEEME.md` (CF-DOC-099): Adaptador principal de contexto e instrucciones de operación.
*   `arquitectura/01_PATRON_MODULO_MAESTRO.md`: Plantilla técnica de referencia para diseño de módulos.
*   `desarrollo/02_ESTANDARES_DE_CODIGO.md`: Guías de type hints, nomenclatura y precisión financiera.
